# Planificación de Procesos

Simulador de planificación de procesos desarrollado en **C# con .NET** para el Trabajo Práctico Integrador de Sistemas Operativos.

Implementa dos algoritmos:
- FCFS (First Come, First Served).
- Round Robin (quantum configurable).

El programa muestra los tiempos de espera y retorno, el orden de despacho, los diagramas de Gantt y una tabla comparativa.

## Requisitos

- Tener instalado el SDK de .NET.

Descarga: https://dotnet.microsoft.com/download

## Ejecución

Abrir una terminal en la carpeta del proyecto y ejecutar:

```bash
dotnet run
```

El programa solicitará los datos de los procesos y el quantum para realizar la simulación.
